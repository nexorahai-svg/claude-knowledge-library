## S16 — Openverse

- **نوع:** پست فارسی (متن کپی‌شده توسط کاربر؛ نویسنده نامشخص) + API
- **لینک‌های دقیق:**
  - API: https://api.openverse.org/v1/
  - آمار صدا: https://api.openverse.org/v1/audio/stats/
  - مستندات: https://docs.openverse.org/
- **روش بررسی:** ✅ درخواست مستقیم به API: شمارش فایل‌ها، خواندن هدرهای سقف درخواست، تست فیلترهای مجوز و دسته
- **چه برداشتیم:** آمار دقیق، محدودیت‌ها، ترکیب درست فیلتر مجوز، فیلد `attribution`
- **وضعیت:** ✅ ادعای «۵.۲ میلیون فایل» و «بدون کلید» درست است؛ هشدار پست درباره‌ی مجوز هم درست است
- **استفاده‌شده در:** [کتابخانه‌ی صدا](../domains/social-media/sound-library.md)
- **دفعه‌ی بعد چک شود:** `/v1/audio/stats/`؛ هدرهای `x-ratelimit-*`؛ مقادیر مجاز `category` (خطای API آن‌ها را فهرست می‌کند)
