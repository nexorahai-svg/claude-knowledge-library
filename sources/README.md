# فهرست مرکزی منابع

> **هدف این سند:** هر منبعی که در این کتاب راهنما استفاده شده، با لینک دقیق، تاریخ و روش بررسی، و اینکه **دفعه‌ی بعد دقیقاً چه چیزی دوباره چک شود**. هدف این است که هر منبع را بتوان دوباره تحقیق کرد و سند مربوطش را به‌روز کرد.
> **آخرین بررسی کل فهرست:** ۲۰۲۶-۱۰-۱۷
>
> **شماره‌ی منبع (S01، S02…) ثابت است** و هرگز عوض یا دوباره استفاده نمی‌شود. سندهای دیگر با همین شماره به این‌جا لینک می‌دهند. منبع حذف‌شده با وضعیت «بایگانی» می‌ماند.

---

## روش دوباره‌تحقیق یک منبع

1. لینک‌های «لینک‌های دقیق» را باز کن (برای X و سایت‌هایی که ورود می‌خواهند، از ابزار خواندن صفحه یا مرورگر استفاده کن)
2. موارد «دفعه‌ی بعد چک شود» را یکی‌یکی بررسی کن
3. اگر چیزی عوض شده: سندهای ستون «استفاده‌شده در» را اصلاح کن
4. «آخرین بررسی» همین منبع را به‌روز کن
5. یک ردیف به CHANGELOG اضافه کن

پرامپت آماده:
```text
Re-research source [S0X] in ~/Desktop/knowledge-library/sources/README.md.
Open every link listed, check each item under "next check", compare with what the
playbook documents say, update those documents and this entry with what changed
(keep confidence labels ✅ 🧭 ❓), and add a CHANGELOG row. Report what changed.
```
