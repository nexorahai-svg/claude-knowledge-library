# Contributing

Thank you for helping keep this library accurate.

This repository is a **published copy** of a library we maintain privately and verify every day, so pull requests are not merged directly. The fastest ways to help:

1. **Suggest a tool** — open an issue with the "Suggest a tool" form.
2. **Report an error or outdated fact** — use the "Report an error" form with a primary-source link.
3. **Ask or share** in [Discussions](https://github.com/nexorahai-svg/claude-knowledge-library/discussions).

Our rules for every card and document:

- **Primary sources only** for facts (official docs, pricing pages, licence files, release notes). Posts and videos are leads, not proof.
- **Confidence labels:** ✅ checked against the primary source · 🧭 strong secondary signal · ❓ unverified · 🔬 tested in a real project.
- **No copying** of other people's text, prompts, designs or code — we describe patterns in our own words.
- **Third-party plugins, MCP servers and skills** are read file by file before any verdict.

Accepted suggestions are credited in the change notes.
