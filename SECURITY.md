# Security

This repository contains documentation and helper scripts. If you find a security problem — a script that could harm a user's machine, a leaked credential, or a recommendation that creates a real risk — please **do not open a public issue**. Email **nexorah.ai@gmail.com** with the details; we reply within a few days and credit reporters who want it.

Safety rules we apply in the library itself: third-party plugins, hooks, MCP servers and skills are read before any recommendation, risky ones are marked ⛔ hold, and nothing is installed or run on your machine without your request.
