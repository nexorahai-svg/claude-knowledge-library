# حوزه‌ی شبکه‌های اجتماعی: ویدیو، عکس، پست

> **هدف این حوزه:** ساختن محتوای شبکه‌های اجتماعی با Claude و ابزارهای بررسی‌شده: ویدیوی کوتاه و تبلیغاتی، تصویر و گرافیک پست، متن و زیرنویس، صدا و موسیقی، و نسخه‌های مختلف برای هر شبکه.
