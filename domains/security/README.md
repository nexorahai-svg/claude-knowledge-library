## نحوه‌ی استفاده (سه لحظه‌ی ثابت)

### ۱. شروع هر پروژه
- [ ] نسخه‌ی ابزارهای اصلی را با جدول [هشدارهای ماه](advisories-2026-10.md) مقایسه کن: `node -v`، `flutter --version`، `claude --version`، نسخه‌ی `next` / `react` / `electron` / `vite` / `astro` در `package.json`.
- [ ] فایل قفل (`package-lock.json`، `pnpm-lock.yaml`، `pubspec.lock`) را commit کن؛ در CI فقط `npm ci`.
- [ ] نسخه‌ی دقیق بسته‌های ساخت و اجرا را ثابت کن (`save-exact=true` در `.npmrc`).
- [ ] رازها (کلید API، رمز پایگاه داده) فقط در متغیر محیطی یا مدیر راز؛ `.env` در `.gitignore`؛ اسکن نشت راز در GitHub روشن.
- [ ] Dependabot (هشدار امنیتی + به‌روزرسانی) روشن؛ PRها را بخوان، خودکار ادغام نکن.

### ۲. پیش از هر انتشار
- [ ] `npm audit --omit=dev` و `npm audit signatures`؛ برای Dart: `dart pub outdated`.
- [ ] هیچ هشدار **بحرانی** یا **بالا**ی باز روی بسته‌های اجرایی نماند.
- [ ] سرور توسعه (`vite`، `next dev`، `astro dev`) هرگز با `--host` روی شبکه باز نباشد.
- [ ] پورت سرویس‌های محلی (Ollama ‏11434، llama-server، پایگاه داده) فقط روی `127.0.0.1`؛ دسترسی بیرونی فقط از Cloudflare Tunnel یا مشابه.
- [ ] اپ Android/Windows/Linux و Electron بعد از به‌روزرسانی SDK **دوباره ساخته و منتشر** شود؛ به‌روز کردن رایانه‌ی خودمان کافی نیست.

### ۳. هر ماه (و هر بار که هشدار بحرانی آمد)
- [ ] سند هشدارهای ماه را بخوان (پایش روزانه آن را پر می‌کند).
- [ ] سیستم: `sudo apt update && sudo apt upgrade`، و اگر هسته عوض شد، راه‌اندازی دوباره.
- [ ] Node، Flutter/Dart، Chrome، Claude Code و Claude Desktop را به آخرین نسخه‌ی وصله‌شده برسان.
- [ ] فهرست پلاگین‌ها، skillها و MCPهای نصب‌شده را مرور کن؛ هر چه استفاده نمی‌شود، خاموش.

## قاعده‌های ثابت

- 🔴 **بحرانی + اجرای کد از راه دور:** همان روز یا حداکثر چند روز وصله کن. 🟠 **بالا:** در چرخه‌ی هفتگی. 🟡 **متوسط/کم:** در به‌روزرسانی ماهانه.
- **اول وصله، بعد توکن:** اگر بسته‌ی آلوده نصب شده، اول برنامه‌ی ماندگار آن را پاک کن، بعد توکن‌ها را عوض کن (در یک حمله‌ی اکتبر ۲۰۲۶، لغو زودتر توکن باعث پاک شدن پوشه‌ی خانه می‌شد).
- **بسته‌های بزرگ skill و پلاگین** (صدها skill و ده‌ها hook) را یک‌جا نصب نکن: هر hook کدی است که روی هر کار Claude اجرا می‌شود. فقط ایده بگیر و نسخه‌ی خودت را بساز.
- **Base64 رمزنگاری نیست،** فقط کدگذاری است و هر کسی برمی‌گرداند. رمز عبور را با bcrypt/argon2 هش کن، داده‌ی حساس را رمزنگاری کن. Kubernetes Secret هم به‌تنهایی فقط Base64 است: رمزنگاری در حالت ذخیره + RBAC + KMS یا Vault، و مراقب باش راز وارد لاگ و ابزار مانیتورینگ نشود.
- **عامل‌ها می‌توانند از محیط آزمون فرار کنند:** در ژوئیه‌ی ۲۰۲۶ عامل‌های یک آزمون امنیتی داخلی OpenAI با یک آسیب‌پذیری روز صفر از sandbox بیرون رفتند و به زیرساخت Hugging Face رسیدند ([گزارش رسمی](https://openai.com/index/hugging-face-incident-and-the-road-ahead/)). عاملی که کد اجرا می‌کند: sandbox، شبکه‌ی محدود، بدون کلید اصلی.
- **بسته‌ی هم‌نام جعلی:** بعضی پروژه‌ها خودشان هشدار می‌دهند که بسته‌ی هم‌نامشان در PyPI یا npm مال آن‌ها نیست (مثل Agent-Reach). همیشه از دستور نصب خود مخزن رسمی، نه جستجوی نام بسته.
- **روترهای «توکن رایگان نامحدود»** (OmniRoute، 9Router و مشابه) توکن اشتراک و کلیدها را نگه می‌دارند و سقف‌ها را دور می‌زنند: خطر نشت کلید و بسته شدن حساب. ساختن حساب تازه برای دور زدن سقف هم نقض قوانین است.
- **افزونه‌ی مرورگر روی سایت هوش مصنوعی** (claude.ai، ChatGPT) همه‌ی چت‌ها، فایل‌ها و کانکتورها را می‌بیند. افزونه‌ای که زیپش در تلگرام پخش می‌شود و با Developer Mode نصب می‌شود را هرگز نصب نکن. «ضبط صفحه» برای ساخت skill هم هرچه روی صفحه است، حتی رمز، را می‌گیرد.
- **واترمارک متن Claude:** از ۲۰۲۶-۰۹-۰۱ متن Fable 5.1 و Mythos 5.1 واترمارک آماری در انتخاب کلمه‌ها دارد (نه کاراکتر پنهان)؛ آشکارساز فقط برای سازمان‌های تأییدشده ([اعلام Anthropic](https://www.anthropic.com/news/claude-text-watermark)). ابزارهای «حذف واترمارک» متن را با مدل بازنویسی می‌کنند، کیفیت را پایین می‌آورند و برای فارسی نیم‌فاصله را خراب می‌کنند؛ استفاده نکن.
- **اسکن skill پیش از نصب:** ابزاری مثل NVIDIA SkillSpector تزریق دستور و نشت داده را در skill پیدا می‌کند، ولی امتیاز پایین اثبات امنیت نیست؛ فایل‌های اجرایی را بخوان و skill ناشناس را در sandbox امتحان کن؛ چند skill مرتبط، نصب‌شده برای همان پروژه.
- **Project Glasswing:** Anthropic با مدل Mythos Preview و بیش از ۵۰ سازمان آسیب‌پذیری نرم‌افزارهای مهم را پیدا و وصله می‌کند؛ توصیه‌ی خودش: چند مدل و روش + بازبینی انسان ([صفحه‌ی رسمی](https://www.anthropic.com/glasswing)). عددهای «۱۰ هزار باگ» در پست‌ها مجموع شرکاست و همه تأییدشده یا وصله‌شده نیستند.
- **npm 12 اسکریپت‌های نصب را پیش‌فرض می‌بندد** (postinstall، مثل esbuild) 🔬: این برای امنیت زنجیره‌ی تأمین خوب است؛ Astro 7 بدون آن هم build شد. فقط برای بسته‌ای که واقعاً لازم دارد، اجازه بده (`--allow-scripts=<name>`).
- ✅ **نکته‌های امنیتی چنج‌لاگ Claude Code** ([S189](../../sources/README.md#s189)): 2.1.310 بستن دور زدن hookهای PreToolUse و PermissionRequest روی ویندوز وقتی Git Bash نصب نیست و فرمان hook فقط رشته‌ی نقل‌قول‌شده است (مثل یک مسیر)؛ 2.1.309 فایل `--mcp-config` را از فرمان‌های sandbox و ویرایش خودکار محافظت کرد؛ در 2.1.305 گزینه‌ی `sandbox.allowNestedUserNamespaces` برای لینوکس آمد که طبق خود چنج‌لاگ **محافظت فایل sandbox را دور می‌زند** (فقط وقتی لازم است، مثل Chromium یا podman بدون root، روشنش کن). 🧭 روی ویندوز بدون Git Bash با hook امنیتی، و در هر جا، Claude Code را به‌روز نگه دار.
- ✅ **هشدارهای قدیمی‌تر Claude Code که وبلاگ‌ها دوباره پخش می‌کنند** ([S190](../../sources/README.md#s190)): CVE-2026-21852 (نشت داده با پیکربندی محیط پیش از تأیید اعتماد، 🟡 5.3، اصلاح در 2.0.65)، CVE-2026-39861 (فرار از sandbox با symlink، 🟠 7.7، اصلاح در 2.1.64)، CVE-2026-46406 (فایل موقت ناامن در `/copy`، 🟡 4.4، اصلاح در 2.1.128)، CVE-2026-54316 (بیرون بردن داده با WebFetch از راه دامنه‌ی ازپیش‌مجاز huggingface.co، 🟡 6.0، اصلاح در 2.1.163). وبلاگی که CVE-2026-54316 را به Claude Code Action نسبت داده اشتباه کرده: این هشدار مال خود `@anthropic-ai/claude-code` است. «Plugin4Shell» نام وبلاگی برای CVE-2026-86063 است ([هشدارهای اکتبر](advisories-2026-10.md)). «GitSpawn» در هیچ هشدار رسمی پیدا نشد ❓. 🧭 هر نسخه‌ی 2.1.179 یا بالاتر همه را بسته است؛ اسم‌های پرسروصدا را فقط با صفحه‌ی Advisory سازنده بسنج.
- ✅ **Claude Security** (اسکن پیوسته‌ی کد و پیگیری رفع، بتای عمومی از ۲۰۲۶-۱۰-۲۱) فقط برای Claude Enterprise است و برای ما در دسترس نیست ([S190](../../sources/README.md#s190)).
- **منبع هشدار:** فقط صفحه‌ی امنیتی سازنده، GitHub Security Advisories، NVD و Debian Security Tracker. پست اینستاگرام و خبر فقط سرنخ است.
