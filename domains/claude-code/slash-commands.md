# دستورهای `/` و میان‌برهای Claude Code

> **نوع سند:** مرجع
> **هدف این سند:** دستورهای کمترشناخته‌ی Claude Code که در کار روزانه هزینه را کم، اشتباه را برگشت‌پذیر و کار موازی را ساده می‌کنند؛ با مثال کاربردی.
> **موضوع تحقیق:** جدول دستورها و میان‌برهای صفحه‌کلید در مستندات رسمی، و changelog اکتبر ۲۰۲۶.
> **منابع:** [S154 دستورهای / و میان‌برها](../../sources/README.md#s154)
> **آخرین بررسی:** ۲۰۲۶-۱۰-۲۵
> **دفعه‌ی بعد چک شود:** ۲۰۲۶-۱۱-۰۸ — تاریخ آمدن `/goal`، `/recap`، `/fork`، `/subtask`، `/import` در changelog (بازه‌ی جولای تا سپتامبر ۲۰۲۶ خوانده نشد)؛ کدام دستورها در اپ دسکتاپ کار می‌کنند.

---

همه ✅ از https://code.claude.com/docs/en/commands.md و https://code.claude.com/docs/en/interactive-mode.md (۲۰۲۶-۱۰-۲۵)، مگر برچسب دیگر. فهرست کامل حدود ۱۱۰ دستور در خود صفحه است؛ این‌جا فقط آن‌هایی که ارزش عملی بالا دارند.

## قاعده‌های کلی
- دستور فقط در **اول پیام** شناخته می‌شود. تا ۶ skill را می‌شود زنجیر کرد: `/skill-a /skill-b کار`.
- دستوری که وسط کار Claude فرستاده شود صف می‌شود، جز چند تا که فوراً اجرا می‌شوند (`/status`، `/tasks`، `/usage`؛ `/fast` وسط نوبت).
- 🧭 سند برای ترمینال نوشته شده و جز `/desktop` و `/rename` چیزی درباره‌ی اپ دسکتاپ نمی‌گوید. 🔬 در اپ دسکتاپ، دستورهایی که پنجره‌ی ترمینال باز می‌کنند (`/config`، `/permissions`، `/hooks`) در دسترس نیستند (جلسه‌ی یک پروژه‌ی مشتری، دفتر پروژه‌ها).

## گنج‌های پنهان

| دستور | کار | کی به کار بیاید |
|---|---|---|
| `/btw سؤال` | پرسش کناری که به تاریخچه اضافه نمی‌شود؛ بدون سؤال، جواب‌های قبلی را مرور می‌کند | سؤال سریع وسط کار بلند بی‌آنکه متن جلسه سنگین شود |
| `/rewind` (`/undo`، `/checkpoint`) یا Esc Esc روی ورودی خالی | برگرداندن کد و گفتگو به نقطه‌ی قبل، یا «خلاصه از این‌جا» | ⚠️ تغییرهای دستور Bash برنمی‌گردد ([بررسی خودکار](verification.md)) |
| `/branch [نام]` | شاخه‌ی گفتگو از همین نقطه؛ برگشت با `/resume` | امتحان راه پرریسک بدون خراب کردن مسیر اصلی |
| `/fork [کار]`، `/subtask کار` | کپی گفتگو در جلسه‌ی پس‌زمینه / زیرعامل پس‌زمینه با همه‌ی متن | رندر یا تحقیق موازی در حالی که این‌جا کار ادامه دارد |
| `/goal شرط` | ادامه در چند نوبت تا شرط برقرار شود | «تا تست‌ها سبز شوند» بی‌آنکه هر بار بنویسی |
| `/context`، `/skill-doctor` | نقشه‌ی پر شدن context؛ هزینه‌ی هر skill به توکن | وقتی پلاگین و skill زیاد است ([هزینه](cost-efficiency.md)) |
| `/compact تمرکز`، `/autocompact [auto\|توکن]` | خلاصه با تأکید دلخواه؛ تعیین آستانه‌ی فشرده‌سازی خودکار (از 2.1.288 برای هر مدل جدا) | سر هر مرحله‌ی کار |
| `/usage` (`/cost`، `/stats`) | هزینه، سقف و آمار؛ از 2.1.305 هشدارها یک‌خطی و با `f` اصلاح می‌شوند | آخر هر جلسه‌ی سنگین |
| `/recap` | خلاصه‌ی یک‌خطی جلسه | برگشتن به جلسه‌ی قدیمی |
| `/diff` | همه‌ی تغییرهای پوشه، از جمله ویرایش‌های Claude | پیش از commit |
| `/copy [N]` | کپی N‌امین پاسخ آخر یا یک تکه کد | برداشتن متن کپشن یا دستور |
| `/export [فایل]` | گفتگو به متن ساده | یادداشت یا تحویل به جلسه‌ی دیگر |
| `/loop [فاصله] کار`، `/schedule` | تکرار در همین جلسه / کار زمان‌بندی‌شده‌ی ابری | ⚠️ قانون کاربر: هیچ حلقه‌ای روشن نماند |
| `/background`، `/tasks`، `/stop` | جدا کردن جلسه به پس‌زمینه و مدیریت کارهای پس‌زمینه | کار بلند (ترمینال) |
| `/advisor [مدل\|off]` | مدل دوم در لحظه‌های مهم راهنمایی می‌دهد | تصمیم سخت بدون عوض کردن مدل اصلی |
| `/effort`، `/fast`، `/model` (کلید `s` فقط برای همین جلسه) | کنترل هزینه و سرعت | ارزان‌ترین مدلی که درست کار می‌کند |
| `/code-review [سطح\|ultra]`، `/simplify`، `/security-review` | بازبینی خطا، پاک‌سازی کد با ۴ عامل، بررسی امنیتی شاخه | پیش از انتشار |
| `/fewer-permission-prompts` | فهرست مجاز فقط‌خواندنی از روی جلسه‌های قبلی | پرسش اجازه‌ی کمتر |
| `/import codex\|gemini\|cursor --dry-run` | آوردن تنظیم، MCP، زیرعامل و skill از آن ابزارها؛ اول پیش‌نمایش | مهاجرت |
| `/reload-skills`، `/reload-plugins` | خواندن دوباره بدون راه‌اندازی مجدد | بعد از نصب skill |

حذف‌شده: `/pr-comments` (2.1.91)، `/vim` (2.1.92؛ از `/config` ← Editor mode)، `/ultraplan` (به‌جایش plan mode).

## میان‌برها (ترمینال)
- `!` اول پیام: اجرای دستور شل و افزودن خروجی به جلسه. `@`: پیشنهاد مسیر فایل (و جلسه‌های زنده‌ی دیگر). `?` روی ورودی خالی: راهنمای میان‌برها.
- ❓ `#` برای حافظه در جدول Quick commands دیگر نیست؛ `/memory` را بزن.
- Esc: توقف (کار انجام‌شده می‌ماند). Esc Esc: با متن، پیش‌نویس را پاک و در تاریخچه ذخیره می‌کند؛ بدون متن، منوی rewind.
- Shift+Tab (در بعضی ویندوزها Alt+M): چرخش حالت اجازه. Alt+P: عوض کردن مدل بی‌آنکه متن پاک شود. Alt+O: fast mode. Alt+T: فکر طولانی (روی مدل‌های ۵٫۵ و Fable اثری ندارد چون همیشه فکر می‌کنند).
- Ctrl+B: فرستادن Bash و عامل‌های در حال اجرا به پس‌زمینه. Ctrl+X Ctrl+K (دو بار): توقف همه‌ی زیرعامل‌های پس‌زمینه. Ctrl+T: فهرست کارها. Ctrl+O: نمای کامل گفتگو.
- Ctrl+S: کنار گذاشتن متن نیمه‌نوشته (دوباره روی ورودی خالی = برگرداندن). Ctrl+G: ویرایش پیام در ویرایشگر بیرونی. Ctrl+R: جستجو در تاریخچه. Ctrl+V: چسباندن عکس (ویندوز/WSL: Alt+V).
