# کتابخانه‌ی دانش

> مرجع دانش برای: **ساخت اپلیکیشن چندسکویی، ساخت وبسایت، و ساخت محتوای شبکه‌های اجتماعی (ویدیو، عکس، پست)**؛ با ابزارها، روش‌ها و منابع معتبر، بررسی‌شده با منبع اصلی، تا در هر پروژه از صفر تحقیق نکنیم. با هر تحقیق تازه به‌روز می‌شود.
> **آخرین بررسی:** ۲۰۲۶-۱۰-۱۷




## قانون‌های پایه

1. **ما چیزی کپی نمی‌کنیم.** از منابع فقط اصول و الگو یاد می‌گیریم؛ طراحی، متن و کد را خودمان می‌سازیم.
2. **فقط منبع اصلی ملاک حقیقت است.** پست‌ها اغلب اغراق یا تبلیغ می‌کنند؛ فاصله‌ی ادعا و واقعیت ثبت می‌شود.
3. **برچسب اطمینان روی هر ادعای مهم:**
   - ✅ **تأییدشده:** از منبع اصلی بررسی شد
   - 🧭 **قاعده‌ی تجربی:** توصیه‌ی رایج، نه قانون
   - ❓ **تأییدنشده:** قبل از استفاده تست کن
   - 🔬 **در پروژه امتحان شد:** فقط وقتی ابزار یا روش در یک پروژه‌ی واقعی استفاده شد و نتیجه ثبت شد. ✅ یعنی «منبع اصلی این را می‌گوید»؛ 🔬 یعنی «کار کرد».
4. **هر ابزار یک کارت با حکم دارد:** ✅ استفاده کن · 🧪 آزمایش کن · 👀 زیر نظر · ⛔ استفاده نکن
5. **اطلاعات تاریخ انقضا دارد:** ابزار قیمت‌دار هر ۳۰ روز، ابزار رایگان هر ۹۰ روز دوباره چک می‌شود.
6. **هر پروژه ملزم است بهترین و جدیدترین ابزار تأییدشده را استفاده کند و هر یافته‌ی تازه را به کتابخانه برگرداند**. این قانون برای مهارت سراسری و `~/.claude/CLAUDE.md` هم نوشته شده (روی هر رایانه باید نصب شوند).

## ساختار

```text
README.md              همین فایل: نقشه و قانون‌ها
CLAUDE.md              قانون‌های کار Claude در این پوشه
CHANGELOG.md           تاریخچه‌ی تغییرات
llms.txt               فهرست کوتاه خودکار برای Claude (اول این خوانده می‌شود؛ مصرف توکن کمتر)
catalog/               یک کارت برای هر ابزار + فهرست خودکار (README.md) + نسخه‌ی ماشین‌خوان (index.json)
dashboard/             رادار تصویری (template.html → index.html)
domains/               دانش هر حوزه: website، apps، social-media، claude-code
sources/README.md      فهرست مرکزی منابع با شماره‌ی ثابت (S01، S02…) و «دفعه‌ی بعد چک شود»
research/              برنامه‌ی تحقیق X، حساب‌ها با نمره‌ی اعتبار، سنجش ادعاهای عددی، فهرست پایش منابع رسمی، و inbox (غربال خام)
starters/              قالب شروع کد (flutter-app: سیستم طراحی، ۸ سبک، ناوبری تطبیقی، آزمون‌ها)
scripts/               build_all.py همه را می‌سازد و همه‌ی بررسی‌ها را اجرا می‌کند
archive/               نسخه‌های قدیمی و کارت‌های خارج از تمرکز (به‌روز نمی‌شوند)
```

**مسیر یک یافته‌ی تازه:** لینک، پست، پایش منابع رسمی یا تجربه‌ی یک پروژه → `research/inbox` (غربال) → تحقیق با منبع اصلی → کارت در `catalog/` و دانش در `domains/` → منبع در `sources/` → یک ردیف در CHANGELOG.

## نحوه‌ی استفاده

**در هر پروژه:** مهارت سراسری `knowledge-library` برای Claude Code در نظر گرفته شده (باید روی هر رایانه نصب شود؛ اگر نصب نبود، جمله‌ی پایین لازم است). وقتی Claude در هر پوشه‌ای ابزار انتخاب می‌کند یا پروژه‌ای شروع می‌کند، اول این کتابخانه را می‌خواند و فقط اگر جواب این‌جا نبود تحقیق می‌کند. می‌توانی صریح هم بگویی:

```text
Check my knowledge library first (~/Desktop/knowledge-library) and follow it.
```

**اضافه کردن یافته‌ی تازه:** لینک یا متن پست را در همین پوشه به Claude بده. طبق [CLAUDE.md](CLAUDE.md) بررسی و ثبت می‌شود.

**نگهداری** (در همین پوشه): یک دستور همه‌چیز را می‌سازد و بررسی می‌کند (کاتالوگ، `llms.txt`، داشبورد، کیفیت سندها، لینک‌ها، موارد منقضی):

```bash
python3 scripts/build_all.py
```

**نوع سندها (Diátaxis):** هر سند در سربرگش می‌گوید از کدام نوع است: «دستورالعمل» (چطور یک کار را انجام دهم)، «مرجع» (فهرست و جدول برای مراجعه)، «توضیح» (چرا و چگونه کار می‌کند)، یا «راهنمای قدم‌به‌قدم» (یادگیری از صفر؛ هنوز نداریم).
