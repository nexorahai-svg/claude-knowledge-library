# Magic UI

## چیست
✅ کامپوننت‌های متحرک برای لندینگ‌پیج (React، Next.js، Tailwind، سبک shadcn، Motion). حدود ۲۲.۷ هزار ستاره، فعال (۲۰۲۶-۱۰-۱۷).
✅ نصب و اجرا (https://magicui.design/docs/installation، ۲۰۲۶-۱۰-۲۷): pnpm dlx shadcn@latest add @magicui/globe

## کی استفاده کنیم
🧭 اولین انتخاب برای افکت‌های آماده‌ی لندینگ (نوار لوگو، متن متحرک، پس‌زمینه‌ی ذره‌ای) در پروژه‌های React.
