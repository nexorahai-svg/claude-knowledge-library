# OpenDesign

## چیست
✅ یک اپ دسکتاپ و وب، محلی و متن‌باز (Apache-2.0)، از شرکت nexu-io. با عامل کدنویس نمونه‌ی اولیه، سایت، اسلاید، تصویر و ویدیوی موشن می‌سازد. به Claude Code و حدود بیست عامل دیگر از راه مهارت، CLI و MCP وصل می‌شود (`od mcp install claude`). بدون عامل هم با کلید API خودت کار می‌کند.

✅ بخش موشن آن **HyperFrames** است که خروجی MP4 می‌دهد؛ [کارت HyperFrames](hyperframes.md). پس «جایگزین Claude Motion» در پست یعنی همین ([کارت Claude Motion](claude-motion.md)).

✅ فعال: نسخه‌ی v0.25.0 در ۲۰۲۶-۱۰-۱۵، آخرین تغییر امروز. حدود ۱۰۲ هزار ستاره در شش ماه (ساخته‌شده ۲۰۲۶-۰۴-۲۸). ❓ این رشد غیرعادی سریع است؛ اعتبارش را نسنجیدیم.

## کی استفاده کنیم
👀 هنوز نه. 🧭 برای ویدیوی موشن، مسیر کتابخانه (کد ← رندر با [HyperFrames](hyperframes.md) یا [Remotion](remotion.md)) را مستقیم داریم و یک لایه‌ی اضافه لازم نیست. اگر روزی فضای کار تیمی با نظر دادن روی طرح لازم شد، روی یک پروژه‌ی آزمایشی با تله‌متری خاموش امتحانش کن.

## قیمت و مجوز
✅ کد رایگان و Apache-2.0. ✅ سرویس ابری پولی «OpenDesign Go» دارد: ماه اول ۸ دلار با اعتبار مدل (README). صفحه‌ی اصلی «۰ دلار برای مدت محدود» نشان می‌دهد.

## ریسک و هشدار
⚠️ **تله‌متری پیش‌فرض روشن است** (PRIVACY.md): در اولین اجرا «اشتراک» یا «عدم اشتراک» را می‌پرسد. اگر «اشتراک» و «محتوای گفتگو» هر دو روشن باشند، پرامپت‌ها، جواب‌ها و ورودی و خروجی ابزارها (کوتاه‌شده و پاک‌سازی‌شده) فرستاده می‌شوند. ضبط جلسه با پوشاندن متن هم دارد. یک کانال «ایمنی و پایداری» همیشه روشن است و با کلید خاموش نمی‌شود. 🧭 برای کار مشتری: «عدم اشتراک» را بزن.
⚠️ یک سرور MCP و پروسه‌ی daemon نصب می‌کند. طبق قانون کتابخانه، قبل از نصب فایل‌هایش را بخوان ([امنیت MCP](../domains/claude-code/mcp-safety.md)).
⚠️ README پر از تبلیغ اعتبار ابری است. پست معرفی، تله‌متری و طرح پولی را نگفت.
