# Solid Glass

## چیست
✅ (GitHub API و README، ۲۰۲۶-۱۰-۳۱) مخزن سازمان deeplethe؛ ساخته‌شده ۲۰۲۶-۱۰-۱۲، آخرین push ۲۰۲۶-۱۰-۲۹، حدود ۲ هزار ستاره، MIT. سیستم طراحی «شیشه‌ی جامد» روی shadcn/ui با Tailwind 4 و React 19، در حالت روشن و تیره؛ رجیستری ۱۳ موردی، بلوک‌های صفحه‌ی کامل (مثلاً فضای کار عامل) و صفحه‌ی Create برای تنظیم. فایل NOTICE تأیید می‌کند بخش بزرگی از کد از shadcn/ui (MIT) برداشته شده؛ پس ارزش آن در «سبک و رجیستری» است، نه کامپوننت‌های تازه. ❓ کیفیت و دسترس‌پذیری آزموده نشد.

🧭 برای داشبورد یا رابط چت/عامل بر پایه‌ی React و shadcn که ظاهر آرام و خوانا می‌خواهد. برای اپ Flutter یا سایت ایستا بی‌ربط است. هنوز در هیچ پروژه‌ای آزموده نشده. دیگر کتابخانه‌های شیشه‌ای را کنار [liquid-glass](liquid-glass.md) ببین.
