# Kage

## چیست
✅ کتابخانه‌ی طراحی با تفکیک کامپوننت (هیرو ۳۲۳، شبکه‌ی ویژگی ۸۴۶) و سبک (مینیمال، تیره، ادیتوریال، بروتالیست، بنتو). برای هر طراحی یک پرامپت توصیفی تولیدشده با هوش مصنوعی. **MCP باز** در `https://kage.design/mcp` بدون کلید.

## کی استفاده کنیم
🧭 پیدا کردن الگوی یک بخش (مثلاً هیرو یا شبکه‌ی ویژگی) و دیدن توصیف ساختارش.

## قیمت و مجوز
✅ شرایط (۲۰۲۶-۰۹-۱۰): پروژه‌ی شخصی Chris Gregori، رایگان، بدون حساب و بدون طرح پولی. پرامپت‌ها را می‌شود تجاری و بدون ذکر نام استفاده کرد، ولی **مجوز کپی برند یا متن سایت‌ها نیست**؛ تحلیل‌ها ممکن است غلط باشند.

## ریسک و هشدار
⚠️ پرامپت‌ها متن تولیدی ماشین‌اند؛ قبل از استفاده بخوان. MCP را بدون تأیید کاربر وصل نکن ([امنیت MCP](../domains/claude-code/mcp-safety.md)). طبق قانون ما، پرامپت را با کلمات خودمان بازنویسی کن.
