# GSAP Skills (رسمی)

## چیست
✅ مخزن رسمی GreenSock (MIT، «Copyright (c) 2026 GreenSock»). ۸ مهارت: هسته، تایم‌لاین، ScrollTrigger، پلاگین‌ها، ابزارها، React، عملکرد، و Vue/Svelte. استفاده‌ی درست API، پاک‌سازی، احترام به کاهش حرکت، و اشتباه‌های رایج.

## کی استفاده کنیم
🧭 در هر پروژه‌ای که GSAP دارد.
```bash
npx skills add https://github.com/greensock/gsap-skills
```
یا در Claude Code: `/plugin marketplace add greensock/gsap-skills`
