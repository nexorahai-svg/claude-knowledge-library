# Wan 2.2 TI2V-5B

## چیست
✅ Apache-2.0؛ ۷۲۰p (۱۲۸۰×۷۰۴) با ۲۴ فریم در ثانیه؛ README دست‌کم ۲۴ گیگابایت با offload می‌گوید، ولی مستندات ComfyUI می‌گوید «روی ۸ گیگابایت خوب جا می‌شود» با offload خودش. مدل‌های A14B هشتاد گیگابایت می‌خواهند. ❓ Wan 2.5 تا 3.0 بازوزن تأیید نشدند (3.0 فقط API، از منابع دست دوم).

## کی استفاده کنیم
👀 تصویر واقعی‌نمای رایگان و محلی وقتی هزینه‌ی API نمی‌خواهیم. ❓ روی RTX 4060 آزموده نشده؛ یک وبلاگ ۱۸۱ ثانیه برای ۵ ثانیه‌ی ۴۸۰p گزارش کرده.
