# ClaudeAnimationBase

## چیست
✅ ۱٬۲۱۷ ستاره. ANIMATION_GUIDE.md (قواعد، روند کار، API کامل)، کاراکتر Clawd با ۳۱ حالت، استودیو و اسکریپت رندر. طبق README با Opus 5.5 روی effort xhigh تست شده.

## کی استفاده کنیم
🧭 نقطه‌ی شروع برای ویدیوی کارتونی؛ یا فقط برای دیدن اینکه یک راهنمای خوب برای مدل چطور نوشته می‌شود.

## قیمت و مجوز
✅ MIT، رایگان. 🧭 کاراکتر Clawd به Anthropic مربوط است؛ قبل از استفاده‌ی تجاری مسئله‌ی برند را بررسی کن.

## ریسک و هشدار
⚠️ render.mjs روی لینوکس **sandbox مرورگر Chrome را خاموش می‌کند** (`--no-sandbox`). بدون GPU کند است (چند ثانیه برای هر فریم).
