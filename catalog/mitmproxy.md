# mitmproxy

## چیست
✅ پراکسی برای دیدن و بررسی ترافیک HTTPS اپ و سایت. مجوز MIT؛ ~۴۶ هزار ستاره، فعال (۲۰۲۶-۱۰-۱۹).

## کی استفاده کنیم
🧪 دیدن همه‌ی درخواست‌های اپ خودمان و SDKهای داخلش؛ آیا هر درخواست احراز هویت دارد. فقط روی خروجی خودمان، داخل ماشین مجازی یا کانتینر ([محافظت از اپ](../domains/apps/app-protection.md)).

## قیمت و مجوز
✅ رایگان، MIT.

## ریسک و هشدار
⚠️ ابزار مهندسی معکوس است: فقط روی نرم‌افزار خودمان. استفاده روی اپ دیگران برای کپی، قانون اول کتابخانه و معمولاً شرایط استفاده و قانون حق نشر را می‌شکند. طبق قانون کتابخانه بدون درخواست کاربر نصب نشود.
