# FLUX API (Black Forest Labs)

## چیست
✅ «مالکیتی بر محتوای شما ادعا نمی‌کنیم» (۱.۲(a))؛ استفاده از خروجی آزاد (۱.۳(e)).

## کی استفاده کنیم

## قیمت و مجوز
✅ (docs.bfl.ai، ۱ اعتبار = ۰.۰۱ دلار، ۲۰۲۶-۱۰-۱۷) FLUX 3 Image هر تصویر: ۷۶۸² ۰.۰۴۱، ۱K ۰.۰۴۸، ۱.۵K ۰.۰۷، ۲K ۰.۱۰، 4K ۰.۶۰۷ دلار. FLUX 3 Klein (وزن باز): ۰.۰۰۸ تا ۰.۰۳۶ دلار (۷۶۸² تا 4K). قیمت API و Playground یکی است.
✅ **تازه:** FLUX 3 ویدیو هم می‌سازد، با صدای هم‌زمان؛ هر ثانیه hd ۰.۱۵، fhd ۰.۲۴، qhd ۰.۲۸، uhd ۰.۴۱ دلار، پیش‌نویس ۰.۰۶؛ ادامه‌ی ویدیو (v2v) کمی گران‌تر. بالاگیری ویدیو هر مگاپیکسل-ثانیه ۰.۰۷ (دقیق) یا ۰.۱۰ (خلاق). ❓ شرایط و مجوز خروجی ویدیو جدا بررسی نشد.
وزن‌های باز مجوز جدا دارند (klein: Apache-2.0؛ dev: غیرتجاری).

## FLUX.2 وزن‌های باز (۲۰۲۶-۱۰-۲۳)
✅ (Hugging Face) مخزن رسمی `black-forest-labs/flux2` (کد Apache-2.0). وزن **FLUX.2 [dev] غیرتجاری** (flux-non-commercial-license) است؛ **FLUX.2 [klein] 4B** با Apache-2.0 برای کار مشتری مجاز است. ⚠️ پست‌ها گاهی به مخزن قدیمی FLUX.1 لینک می‌دهند ([S144](../sources/README.md#s144)).
