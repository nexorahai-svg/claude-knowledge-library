# Venice

## چیست
✅ (جاروی ۲۰۲۶-۱۰-۳۱) سایت اصلی از این شبکه timeout می‌دهد ولی https://docs.venice.ai/overview/pricing پاسخ ۲۰۰ می‌دهد؛ پس سرویس بالاست و هشدار بررسی‌کننده از مسدود بودن مسیر است.
✅ (جاروی ۲۰۲۶-۱۰-۲۸) venice.ai از این شبکه (ایران) پاسخ نمی‌دهد (DNS حل می‌شود، اتصال timeout؛ احتمالاً سد منطقه‌ای یا ضدربات)، ولی مستندات https://docs.venice.ai/overview/pricing باز می‌شود: قیمت API برای هر میلیون توکن، «یک Diem = یک دلار در روز محاسبات»، Claude Fable 5/5.1 ده دلار ورودی و پنجاه دلار خروجی. ❓ قیمت طرح‌های مصرفی (free/pro) تأیید نشد. حکم assess می‌ماند.
✅ (docs.venice.ai/overview/privacy) اپ و API گفتگو، تصویر، ویدیو و صدا با مدل‌های باز. درخواست‌ها از پراکسی Venice می‌گذرند و طبق ادعای خودش «محتوای پرامپت و پاسخ ذخیره یا لاگ نمی‌شود». چهار حالت: Anonymous (هویت از سازنده‌ی مدل پنهان، ولی **متن را سازنده‌ی مدل می‌بیند**)، Private (نگه‌نداشتن داده با قرارداد)، TEE و E2EE. MCP، CLI و راهنمای Claude Code هم دارد.
❓ پست معرفی گفت DeepSeek V4.1 Flash «بی‌سانسور» در اپ رایگان و بی‌محدودیت است؛ سایت اصلی venice.ai از این شبکه باز نشد (timeout) و قیمت و سقف رایگان بررسی نشد. عدد بنچمارک DeepSeek ادعای خود Venice است.

## کی استفاده کنیم
👀 کاری در پروژه‌های ما ندارد. «بی‌سانسور» یعنی محافظ‌های ایمنی مدل برداشته شده؛ برای محصول مشتری مناسب نیست.

## قیمت و مجوز
✅ (https://docs.venice.ai/overview/pricing، ۲۰۲۶-۱۰-۲۶) طرح‌های Pro (اعتبار ۱ دلار در ماه)، Plus (۷۵ دلار) و Max (۲۲۵ دلار). API فقط پرداخت به‌ازای مصرف است؛ حساب رایگان می‌تواند API را با نرخ پولی صدا بزند ولی اعتبار ماهانه ندارد، و برخی مدل‌ها فقط برای طرح‌های پولی‌اند. ادعای پست درباره‌ی API «رایگان و بی‌محدود» با مستندات نمی‌خواند. ❓ سقف رایگان اپ در مستندات نیست؛ venice.ai هنوز از این شبکه باز نمی‌شود (سرویس مرده ثابت نشده).

## ریسک و هشدار
⚠️ داده‌ی مشتری را به آن نده؛ ادعای حریم خصوصی را مستقل نسنجیده‌ایم و در حالت Anonymous متن به سازنده‌ی مدل می‌رسد.
