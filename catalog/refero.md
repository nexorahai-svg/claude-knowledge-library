# Refero (و Refero Styles)

## چیست
✅ refero.design: ده‌ها هزار اسکرین‌شات و جریان وب و iOS. ✅ **Refero Styles** (بتا): «بیش از ۲٬۰۰۰» سبک، هر کدام با یک فایل DESIGN.md قابل خواندن برای Claude Code، Cursor و…، با لینک اتصال MCP.

## کی استفاده کنیم
🧭 Styles را برای پیدا کردن سبک و نوشتن DESIGN.md خودمان امتحان کن؛ طرح پولی فعلاً نه.

## قیمت و مجوز
✅ طرح‌ها: رایگان (جستجوی محدود، بدون MCP و افزونه‌ی Figma)، Pro، Team، Enterprise، مادام‌العمر؛ بدون دوره‌ی آزمایشی. ✅ MCP (`https://api.refero.design/mcp`) فقط در طرح پولی. ❓ قیمت‌ها و رایگان بودن کامل Styles تأیید نشد.

## ریسک و هشدار
⚠️ فایل DESIGN.md متن شخص ثالث است؛ قبل از دادن به Claude بخوان. ❓ مجوز استفاده‌ی دوباره از آن‌ها روشن نیست (شرایط: https://doc.refero.design/legal/terms-of-use.md).
