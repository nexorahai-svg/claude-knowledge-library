# Code and Chill

## چیست
✅ اینستاگرام @_code_and_chill_ (حدود ۵۷ هزار دنبال‌کننده، ۱۰۴ پست) و Threads همان نام. سازنده Hasibul Hasan (برند OVERSHOOT) است، توسعه‌دهنده‌ی React Native با چهار اپ در Google Play (hasib.site). هر چند روز یک داشبورد متحرک تازه منتشر می‌کند (رستوران، مدیریت تیم، پیام مشتری) و برای هر کدام یک **دموی زنده** در `demo.codeandchill.store` دارد. فروشگاه codeandchill.store قالب و کامپوننت را با قیمت یک‌باره می‌فروشد ❓ (قیمت‌ها با JavaScript بار می‌شوند و دیده نشدند).

✅ مهندسی دموی Tavola (داشبورد رستوران، ۲۰۲۶-۱۰-۱۹)، از کد عمومی صفحه:
- **TypeScript ساده با Vite**، بدون React یا Vue؛ انیمیشن با **GSAP** و ScrollTrigger.
- نمودارها **SVG ساخته‌شده با کد** هستند و کشیدن کارت‌ها با رویدادهای pointer است؛ کتابخانه‌ی نمودار یا drag ندارد.
- فونت **Urbanist** با وزن متغیر ۴۰۰ تا ۸۰۰ (OFL، Google Fonts).
- شیشه‌ی مات، پس‌زمینه‌ی چند لکه‌ی نور، تم روشن و تیره، و احترام به `prefers-reduced-motion`.
- یک **«حالت ضبط»** (`?record`) دارد: تنظیمات ذخیره‌شده را نادیده می‌گیرد و منتظر «دستگاه ضبط» می‌ماند. یعنی ریل‌ها با ضبط خودکار صفحه ساخته می‌شوند.
- ❓ اینکه از کدام مدل هوش مصنوعی استفاده می‌کند، جایی گفته نشده. همه‌ی تصویرهای داخل داشبورد با کد ساخته شده‌اند، نه با مدل تصویر.

✅ ریل تازه‌ی «Inventory Management Dashboard» (۲۰۲۶-۱۰-۲۱، https://www.instagram.com/reel/DewEhgSP161/). از تصویر جلد، به زبان خودمان:
- **تم روشن** با پس‌زمینه‌ی خاکستری‌آبی خیلی کم‌رنگ؛ حالت تیره هم دارد.
- **یک رنگ تأکیدی سبز** با هاله‌ی نور نرم پشت عنوان و کارت‌ها؛ بقیه سیاه و سفید.
- **کارت سفید با گوشه‌ی گرد** و حاشیه‌ی سبز کم‌رنگ؛ کمی کج در جلد برای حس حرکت.
- **عکس واقعی محصول** بریده‌شده و بی‌پس‌زمینه کنار داده‌ها.
- **عقربه‌ی نیم‌دایره‌ی خط‌خطی** (gauge با تیک‌های جدا) با عدد درشت درصد.
- تیتر **خیلی ضخیم و فشرده**، و ردیف چهار ویژگی با آیکون خطی کوچک.
- ❓ دموی زنده‌اش پیدا نشد (نشانی‌های حدسی ۴۰۴ دادند)؛ فقط جلد دیده شد.

## الگوهای تازه (پست‌های ۲۰۲۶-۱۰-۲۳ تا ۲۵) 🧭
- **Liquid Glass به سبک iOS:** کارت شیشه‌ای روشن با لبه‌ی درخشان آبی، عدد بزرگ (درآمد) و نمودار خطی نرم؛ یک شیء سه‌بعدی شیشه‌ای کنارش.
- **عقربه‌ی نیم‌دایره با عدد درشت** در کارت تیره، با کلید «روشن/تیره» که خودش بخشی از نمایش است.
- **داشبوردهای موضوعی:** فروش فروشگاه، پلتفرم API هوش مصنوعی، انتشار اپ iOS، ERP، CRM، رستوران (برد آشپزخانه و نقشه‌ی میزها).
- **ریزتعامل‌ها:** فیلد OTP متحرک، نوار پایین «ذوب‌شونده».

## دو ریل نمونه برای «شیشه» (۲۰۲۶-۱۰-۲۷) 🔬
- **«Sales Dashboard Glass UI»** (https://www.instagram.com/reel/De9t_FePi3J/؛ فقط جلد دیده شد، ویدیو بدون ورود باز نمی‌شود): زمینه‌ی **روشن و خنثی** با فضای خالی زیاد؛ شیشه‌ی سفید مات؛ جلوه از **لبه‌ی نارنجی درخشان** و هاله‌ی نرم پشت کارت؛ یک رنگ تأکیدی؛ کارت‌های ویژگی خاکستری مات بی‌درخشش؛ کارت اصلی کمی کج.
- **«Dashboard Animation / Sales CRM»** (عکس‌هایی از همان صفحه): **شیشه‌ی دودی تیره روی یک عکس واقعی و تار از اتاق** (پنجره و نور)؛ نوشته‌ی سفید؛ تأکید هلویی؛ قرص زبانه‌ها **مثل قطره** حرکت می‌کند: لبه‌ی جلو زودتر و تندتر، لبه‌ی عقب بعد می‌رسد (کد GSAP و clip-path در ریل، که از آن کپی نکردیم).
- 🔬 درس پروژه (یک پروژه‌ی واقعی): نورهای رنگارنگ و تند پشت شیشه («جیغ») **جلوه‌ی شیشه را از بین می‌برد**؛ آنچه کار کرد زمینه‌ی آرام + لبه‌ی درخشان تک‌رنگ (روز) و **«اتاق» تار ساخته‌شده با گرادیانت** به جای عکس (شب)، با پرده‌ی تیره‌ی کافی تا متن AA بماند. حرکت قطره‌ای با Web Animations: سه قاب (جای قبلی، کش‌آمده تا لبه‌ی جلوی مقصد در ۴۲٪، مقصد).

## فرمول کاور ریلز (برای پست‌های خودمان، با طرح و دارایی خودمان) 🧭
تیتر دوخطی خیلی ضخیم و فشرده (خط اول مشکی، خط دوم رنگی با درخشش ملایم) ← نشان کوچک فناوری («HTML + CSS + TS») ← حباب گفتار دست‌نویس («Switch to dark!») ← یک شیء سه‌بعدی واقعی + فلش دست‌کشیده ← کارت محصول درخشان ← ردیف ۴ آیکون خطی (کد تمیز، انیمیشن نرم، رابط مدرن، واکنش‌گرا). پس‌زمینه‌ی خاکستری خیلی روشن، فضای خالی زیاد. برای ریلز معرفی کتابخانه یا اپ‌ها همین ساختار را با رنگ و شیء خودمان بساز ([سبک‌های موشن](../domains/social-media/motion-design-styles.md)).

## کی استفاده کنیم
🧪 به‌عنوان **مرجع الهام و الگو** برای داشبورد، پنل مدیریت و ریل معرفی محصول؛ به‌ویژه برای پروژه‌ی رستوران (یک پروژه‌ی سفارش با QR). دستور ساخت را در [سبک‌های طراحی](../domains/website/02-design/design-styles.md) به زبان خودمان نوشته‌ایم. قالب را فقط بعد از خواندن متن مجوز بخر.

✅ **فروشگاه رسمی (۲۰۲۶-۱۰-۲۳):** codeandchill.store، حدود ۵۰ داشبورد آماده از ۳۵ دلار (رستوران Tavola حدود ۱۱۰ دلار)، «یک بار بخر، برای هر مشتری استفاده کن»، به‌روزرسانی رایگان، ۱۴ روز بازگشت پول، پرداخت با Polar؛ دموی زنده پیش از خرید. برای پروژه‌ی فوری مشتری، **خرید مجوز راه قانونی استفاده‌ی مستقیم** است؛ متن مجوز را پیش از خرید بخوان (تعداد پروژه، اجازه‌ی فروش دوباره) ❓.
