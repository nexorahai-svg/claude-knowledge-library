# Midjourney

## چیست
✅ شرایط رسمی (اجرایی از ۲۰۲۶-۰۵-۲۷، docs.midjourney.com) صریح می‌گوید: استفاده از ابزار خودکار برای دسترسی، تعامل یا ساختن خروجی ممنوع است؛ Midjourney می‌تواند حساب را هر زمان مسدود کند. ❓ وجود API رسمی بررسی نشد.

## کی استفاده کنیم
🧭 برای کار خودکار با Claude نه.

## قیمت و مجوز
✅ شرکت یا کارمند شرکتی با درآمد سالانه بیش از ۱ میلیون دلار باید طرح Pro یا Mega داشته باشد تا مالک خروجی‌اش باشد. حالت Stealth فقط با Pro/Mega. خروجی «AS IS» و مسئولیت مناسب‌بودن برای استفاده با خود توست.

## ریسک و هشدار
⚠️ ابزارهای غیررسمی که آن را خودکار می‌کنند طبق شرایط رسمی نقض هستند (خطر مسدود شدن حساب).


## به‌روزرسانی 2026-10-25 ([S155](../sources/README.md#s155))
🧭 V8.1 مدل پیش‌فرض از ۲۰۲۶-۰۶-۱۱؛ Edit Model در آزمون. طرح‌ها: Basic ‏۱۰، Standard ‏۳۰، Pro ‏۶۰، Mega ‏۱۲۰ دلار؛ Stealth فقط Pro و Mega. ویدیو: فقط تصویر به ویدیو، ۵ ثانیه تا ۲۱ ثانیه با ادامه، 480p (HD فقط Pro/Mega)، بدون صدا و API. زیباترین سبک برای پیکسار، انیمه و فضایی؛ متن دقیق ضعیف. صفحه‌های رسمی بسته بود (۴۰۳) ❓.
