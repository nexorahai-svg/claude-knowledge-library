# H3 (شبکه‌ی شش‌ضلعی Uber)

## چیست
✅ کتابخانه‌ی C از Uber؛ Apache-2.0؛ v4.5.0 (۲۰۲۶-۰۵-۲۱)؛ فعال. نسخه‌ی رسمی JavaScript (`h3-js`) و Python (`h3-py`) هم v4.5.0 هستند.

## کی استفاده کنیم
✅ وقتی اپ یا سایت مکان دارد: هر نقطه را به یک خانه‌ی شش‌ضلعی تبدیل کن و برای «نزدیک‌ترین راننده یا شعبه» همان خانه و خانه‌های همسایه را جستجو کن؛ منطقه‌ی تحویل را به مجموعه‌ای از خانه‌ها تبدیل کن؛ تقاضا را روی نقشه‌ی گرمایی جمع بزن. ✅ برای Flutter بسته‌های `h3_flutter` (0.7.1، ۲۰۲۵-۱۲-۱۱) و `h3_dart` (0.7.0، ۲۰۲۵-۰۶-۰۴) از جامعه‌اند (ناشر festelo.net، نه Uber)؛ مخزن https://github.com/festelo/h3_dart مجوز Apache-2.0 دارد، بایگانی نشده و ۳ issue باز دارد (https://pub.dev/api/packages/h3_flutter ، https://api.github.com/repos/festelo/h3_dart).

## قیمت و مجوز
✅ رایگان، Apache-2.0.

## ریسک و هشدار
کم. ❓ ادعای پست که اسنپ از H3 استفاده می‌کند در منبع عمومی پیدا نشد.
