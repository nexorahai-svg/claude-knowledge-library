# H3 (شبکه‌ی شش‌ضلعی Uber)

## چیست
✅ کتابخانه‌ی C از Uber؛ Apache-2.0؛ v4.5.0 (۲۰۲۶-۰۵-۲۱)؛ فعال. نسخه‌ی رسمی JavaScript (`h3-js`) و Python (`h3-py`) هم v4.5.0 هستند.

## کی استفاده کنیم
✅ وقتی اپ یا سایت مکان دارد: هر نقطه را به یک خانه‌ی شش‌ضلعی تبدیل کن و برای «نزدیک‌ترین راننده یا شعبه» همان خانه و خانه‌های همسایه را جستجو کن؛ منطقه‌ی تحویل را به مجموعه‌ای از خانه‌ها تبدیل کن؛ تقاضا را روی نقشه‌ی گرمایی جمع بزن. ❓ برای Flutter بسته‌های `h3_flutter` و `h3_dart` از جامعه هستند، نه Uber؛ نگهداری و مجوزشان را پیش از استفاده چک کن.

## قیمت و مجوز
✅ رایگان، Apache-2.0.

## ریسک و هشدار
کم. ❓ ادعای پست که اسنپ از H3 استفاده می‌کند در منبع عمومی پیدا نشد.
