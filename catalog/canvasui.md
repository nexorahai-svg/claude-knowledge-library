# CanvasUI

## چیست
✅ افکت‌های بصری با API تازه‌ی HTML-in-canvas و WebGL یا WebGPU، مستقل از فریم‌ورک. حدود ۵ هزار ستاره.
```bash
npx shadcn@latest add @canvas-ui/particle-reveal-react
```

## کی استفاده کنیم
🧭 برای یک افکت خاص هیرو، با نسخه‌ی جایگزین برای مرورگرهای ناسازگار.

## قیمت و مجوز
✅ «MIT + Commons Clause» (متن خوانده شد): استفاده، حتی تجاری، داخل سایت یا محصول مجاز است؛ **فروش یا بازنشر خود کامپوننت‌ها** (تنها یا بسته‌بندی‌شده) ممنوع. اعلان کپی‌رایت حفظ شود. سایت: «رایگان برای همیشه».

## ریسک و هشدار
⚠️ متن‌باز استاندارد (OSI) نیست. ❓ پشتیبانی مرورگرها از API تازه بررسی نشد؛ احتمالاً محدود.
