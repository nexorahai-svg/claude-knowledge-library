# Runway

## چیست
✅ اعتبار در ثانیه: Gen-4.5 دوازده، gen4_turbo پنج، Veo 3.1 بیست (با صدا چهل)، Kling 3.0 Pro دوازده، Seedance 2.5 بیست تا ۶۸.

## کی استفاده کنیم
🧭 یک صورت‌حساب برای چند مدل؛ ویرایش با Gen-4.5.

## قیمت و مجوز
✅ مالکیت ادعا نمی‌شود و استفاده‌ی تجاری محدود نیست (۴.۴). ❓ هر اعتبار حدود ۱ سنت.

## ریسک و هشدار
⚠️ جعل هویت ممنوع (۵(v))؛ ساختن محصول رقیب با خروجی ممنوع (۵(viii)). ❓ واترمارک طرح رایگان.

## بازبینی ۲۰۲۶-۱۰-۱۸
✅ مهارت قدیمی `rw-generate-video` بازنشسته شد (پوشه‌ی `legacy/`). افزونه‌ی فعلی: `claude plugin marketplace add runwayml/skills` و `claude plugin install runway-api@runway-dev` (MIT). MCP با OAuth در مرورگر. قیمت هر ثانیه: gen4_turbo ۰.۰۵، gen4.5 ۰.۱۲، veo3.1 بی‌صدا ۰.۲۰ و با صدا ۰.۴۰، veo3.1_fast بی‌صدا ۰.۱۰ دلار.


## به‌روزرسانی 2026-10-25 ([S155](../sources/README.md#s155))
✅ طرح‌ها: Standard ‏۱۵ دلار (۶۲۵ اعتبار)، Pro ‏۳۵ (۲٬۲۵۰)، Max ‏۹۵ (۹٬۵۰۰)؛ از Standard بدون واترمارک. Gen-4.5: ‏۲ تا ۱۰ ثانیه، فقط فریم اول، API ‏۰٫۱۲ دلار در ثانیه؛ Aleph 2.0 ‏۰٫۲۸.
