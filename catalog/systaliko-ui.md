# Systaliko UI

## چیست
✅ مجموعه‌ی بلوک، کارت، انیمیشن اسکرول، بخش فروشگاهی و چند قالب کامل صفحه با React، TypeScript، Tailwind و Motion. سایت می‌گوید بیش از ۶۰ بلوک. نصب با کپی یا از رجیستری shadcn (`https://systaliko-ui.vercel.app/r/<name>.json`). مثلاً `cards-stack` فقط به `motion` وابسته است.
✅ سازنده: Youcef Benmessabih؛ ساخته‌شده ۲۰۲۵-۰۲-۲۲؛ نسخه‌ی 1.1.0 (۲۰۲۶-۰۸-۳۱)؛ حدود ۳۲ ستاره، بدون fork. README خودش می‌گوید **نسخه‌ی بتاست و ممکن است باگ داشته باشد و مرتب عوض شود**.

## کی استفاده کنیم
🧭 به‌عنوان منبع ایده یا یک بلوک خاص که در [Magic UI](magic-ui.md) و [Motion Primitives](motion-primitives.md) نیست. کد را در پروژه کپی و خودت نگهداری کن؛ به به‌روزرسانی سازنده تکیه نکن.
