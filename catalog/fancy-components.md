# Fancy Components

## چیست
✅ MIT؛ حدود ۳٫۳ هزار ستاره؛ آخرین تغییر ۲۰۲۶-۰۳-۱۴. React 19، Next 16، Tailwind 4، کتابخانه‌ی `motion` و matter-js برای فیزیک؛ ساختار ثبت کامپوننت بر پایه‌ی shadcn. ❓ دستور دقیق نصب را از مستندات سایت بردار.
