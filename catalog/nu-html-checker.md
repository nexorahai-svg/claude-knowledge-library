# W3C Nu HTML Checker

## چیست
✅ اعتبارسنج مرجع W3C. سرویس آنلاین، یا محلی با `java -jar vnu.jar` (Java ۱۷+)، بسته‌ی npm `vnu-jar` یا Docker.

## کی استفاده کنیم
🧭 گاه‌به‌گاه روی HTML نهایی ساخته‌شده.

## قیمت و مجوز
✅ MIT، رایگان. ✅ نسخه‌های شماره‌دار بعد از 20.6.30 (۲۰۲۰) متوقف شده‌اند؛ پروژه فقط نسخه‌ی «latest» را آماده‌ی استفاده می‌داند.

## ریسک و هشدار
