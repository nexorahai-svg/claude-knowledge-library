# Bing Webmaster Tools

## چیست
✅ ابزار مالک سایت در Bing: تأیید (با فایل، متا، CNAME یا ورود از Search Console)، ارسال sitemap، IndexNow، گزارش‌ها.

## کی استفاده کنیم
🔬 همراه Search Console در روز انتشار. ✅ Copilot از نمایه‌ی Bing جواب می‌دهد و ChatGPT هم از Bing استفاده می‌کند. در یک سایت مشتری: تأیید با CNAME (بدون proxy) و ارسال sitemap.

🔬 (یک پروژه‌ی مشتری) یک روز پس از ثبت، `site:` هنوز ۰ صفحه‌ی خودی داشت؛ ChatGPT از این نمایه می‌خواند ← [سئو](../domains/website/09-seo/seo-and-ai-search.md).

## قیمت و مجوز
✅ رایگان.

## ریسک و هشدار
🔬 رکورد CNAME تأیید باید «DNS only» باشد، نه proxied.
